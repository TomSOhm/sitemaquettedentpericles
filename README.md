# Cabinet dentaire du Pericles, maquette du site

Maquette du site du Cabinet dentaire du Pericles (Epagny Metz-Tessy), publiée avec GitHub Pages depuis la branche `v2`.
La page est exclue des moteurs de recherche (balises noindex).

## Contenu

- `index.html` : la page (version C, calme organique).
- `css/style.css`, `js/app.js`, `js/dc-runtime.js` : styles et logique de la page.
- `assets/` : photo d'exemple du haut de page, vue aérienne IGN, favicon.
- `design/logos/` : propositions de logo en SVG.
- `docs/retours-client.md` : retours du cabinet et informations à confirmer.
- `CLAUDE.md` : fonctionnement de la page et règles de travail.
- `.nojekyll` : évite le traitement Jekyll de GitHub Pages.

## Voir en local

Dans le dossier, lancer `python -m http.server 8000`, puis ouvrir http://localhost:8000.
