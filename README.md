# Cabinet dentaire du Pericles, maquette du site

Maquette du site du Cabinet dentaire du Pericles (Epagny Metz-Tessy), publiée avec GitHub Pages.
La page est exclue des moteurs de recherche (balises noindex).

## Contenu

- `index.html` : la page d'accueil (Version B, verre clinique), autonome.
- `assets/` : images des objets, des soins et vue aérienne.
- `VersionB.dc.html`, `support.js`, `vendor/` : export brut du canevas de design, non utilisé par le site.
- `.nojekyll` : évite le traitement Jekyll de GitHub Pages.

## Voir en local

Dans le dossier, lancer `python3 -m http.server`, puis ouvrir http://localhost:8000.
